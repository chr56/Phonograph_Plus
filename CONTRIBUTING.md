# Guide to make a contribution

Thank you for taking the time and making an effort to contribute!

------


If you want to report a bug or propose some ideas, **just open a new issue** on GitHub and use the specific template with detailed guildance. 

If you are willing to translate it into other languages, please check Crowdin project in README. It is not suggested to make a raw PR on source codes directly.  

If you want to contribute to the source code, we have provided various documents to help you get started:

- [Build Instructions](./docs/Build_Instructions.md): A rough guide about building it from source.
- [Developer Guide](./docs/Developer_Guide.md): A short overview of the project for developers.
- [Git Commit Rules](./docs/Git_Commit_Rules.md): Guideline on how to make commits in this project. 

You are supposed to read them first before making a contribution to source code.


## Checklist before opening a PR

Thank you! There are some rules, but they are quite simple and short.

- Make sure your commits follow the [Git Commit Rules](./docs/Git_Commit_Rules.md), especially the [**CLEAN** rules](./docs/Git_Commit_Rules.md#commit-content-clean).
- Check the [**Source Code Structure**](./docs/Developer_Guide.md#project-structure) and keep the source hierarchy clean and organized.
- Try to keep source files **under 300 lines**.
- Use the IDEA code style configuration in this repository to **format** code in AS/IDEA.

That's it! Thank you very much for keeping this project tidy and organized.


## LLM / AI Policy

#### AI/LLM-generated code is **broadly acceptable but subject to strict limitations**.

We value **quality** over contribution volume and community. We are open to AI/LLM-assisted contribution, however, we will not lower the quality standard to accommodate it.

- By submitting a PR or patch, you **guarantee its quality and maintainability**. If you cannot stand behind every line, do _not_ open the PR.
- Every AI/LLM-generated line must be **seriously and deeply reviewed by a human.** This can take a long time, and that cost is yours to bear.
- If a contribution is **too heavily AI/LLM-generated** with **little or no meaningful human editing and correcting afterward**, it will be **rejected immediately, without excuses**.
- It is not suggested to exceed **80% AI/LLM-generated content** in the PR. This is just a suggestion, and acceptance still depends on quality, maintainability and final review.
- AI/LLM-dominated contributions will receive **stricter, less forgiving, and literally unfair** scrutiny than contributions by humans.
- **Follow every rule in `CONTRIBUTING.md`.** Violations means immediate rejection.
- **Refuse requested changes or stall too long**, and the PR will be rejected without further excuse.
- **If a PR fails after review and multiple update cycles, or drags on too long**, it would be closed and locked. Open a new PR if it is still needed and wanted.
- Any AI/LLM-assisted contribution can **be rejected without giving a reason**.
