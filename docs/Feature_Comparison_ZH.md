# **与原版 Phonograph 的对比**

_最近更新: 截止至 v2.0.1_

以下列出了与原版 Phonograph 相比的显着修改或增强:

### 界面

- 自动夜间模式
- 解锁 Pro，以及所有主题
- <del>相对简陋的</del> Monet 支持
- 全新设计的文件夹视图
- 全新设计的介绍页
- 可完全定制的播放器界面
- 改进媒体库交互

### 改进

- 应用内手动更改语言
- 歌词对话框内显示歌词时间轴信息, 并可以通过长按进行快速转跳与自动滚动
- 调整歌词字体大小和对齐方式
- 支持更多排序方式
- 支持使用自定义分隔符解析和重组多重艺术家和多重流派
- 使用路径过滤器代替黑名单, 支持排除模式与仅包含模式
- 在歌曲(或文件)弹出菜单中, 快速添加排除名单(黑名单)
- 改善 Android T 以上的原生系统的通知栏图片质量
- 改进 Android 11 及以上版本的存储管理
- 小部件支持深色模式
- 允许在夜间模式下使用另一套配色
- 支持删除歌曲时一同删除歌词文件
- 增大“最近播放”和“最喜爱的歌曲(也即“最常播放”的歌曲)”条目数量(100→150)
- 增强多选
- 改进播放列表支持
- 支持导出和置顶内部数据库播放列表
- 改进菜单, 适当折叠歌曲弹出菜单
- 新增快进和快退按钮，并自定义时间间隔
- 允许标签固定并平铺
- 搜索流派


### 增强

- 倍数播放支持
- 自定义歌曲点击行为
- 支持正在播放列表历史记录
- 支持禁用历史记录
- 增强的主播放器界面
- 内部数据据播放列表
- 全新详情页, 显示歌曲标签等信息
- 全新的音乐标签编辑器，支持更多标签
- Android Auto 支持
- 打断后自动恢复播放
- 自动跳过队列中的不可播放项目支持
- 可选在从任务卡片移除应用时停止服务
- 添加崩溃报告页面
- 适配 [墨·状态栏歌词](https://github.com/Block-Network/StatusBarLyric)
- 支持导出内部数据库和设置以供备份

... 以及更多细小特性!

了解所有的修改、改进与新增功能，请浏览[更新日志](https://phonographplus.github.io/changelogs/changeslogs/changelog-ZH-CN.html)!
